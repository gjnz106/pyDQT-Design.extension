Check Update

by Dang Quoc Truong (DQT)

Version check

UI Toolset›Check Update

What it does

One click, no window - compares the installed pyDQT-Design's local git commit against the latest commit on GitHub and reports whether it's up to date or a newer version is available.

Possible results

Not a git install
the extension folder has no .git - reinstall via pyRevit's Extension Manager using the GitHub URL to enable one-click update checks
Cannot reach GitHub
network/connectivity issue - check your connection and try again
Up to date
installed commit matches (or is a prefix of) the latest commit on the tracked branch
New version available
shows the installed and latest short SHAs, plus how to update

Updating

  1. Use the pyRevit ribbon's own Update button, then Reload, or
  2. Run git pull in the extension's installed folder, then Reload.

Good to know

The check reads whichever branch the local clone's .git/HEAD currently points to, and compares it against that same branch name on GitHub - not always main.
