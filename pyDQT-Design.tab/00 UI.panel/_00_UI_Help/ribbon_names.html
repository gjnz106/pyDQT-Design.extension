UI Toolset›Ribbon Name Manager

What it does

Shortens or restores Revit's ribbon tab names with full control. Reads every live ribbon tab, lets you edit each short name inline, toggle between short and full for all tabs at once, and persists your own mapping - no external Snippets dependency or fixed per-language JSON files like the classic tool needed.

Grid columns

Current Name
the tab's real/original name (read-only)
Short Name
the abbreviation to switch to - double-click to edit

Workflow

  1. Double-click any Short Name cell to type a custom abbreviation. Built-in defaults are pre-filled for common Revit and popular extension tabs (Architecture → Arch, Systems → MEP, and so on).
  2. Apply Short renames every live tab to its short name.
  3. Restore Full puts every tab's original full name back.
  4. Save Map remembers your edited short names so they're pre-filled again next time the tool opens.
  5. Reset puts the Short Name column back to the built-in defaults - this only changes the grid, click Apply Short afterward to actually rename tabs.
  6. Close exits; the status line under the title reports how many tabs the last action changed.

Good to know

Switching to short names and back is non-destructive: the tool remembers each tab's true original name the first time it sees it, so Restore Full works correctly even after repeated renames.
An unsaved edit to a Short Name cell is committed automatically before any button action runs, so there's no need to click away from the cell first.
