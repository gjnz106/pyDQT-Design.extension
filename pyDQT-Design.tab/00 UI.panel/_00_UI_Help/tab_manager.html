Extension Tab Manager

UI Toolset›Extension Tab Manager

What it does

Shows/hides Revit ribbon tabs that belong to installed extensions and add-ins - useful for decluttering the ribbon when several add-ins are installed but only some are in active use. Revit's own built-in tabs (Architecture, Structure, Annotate, and so on) are never listed, so there's no risk of hiding a core tab by mistake.

Workflow

  1. Run the tool - it scans the live ribbon and lists every tab that isn't a recognized Revit built-in or Family Editor tab.
  2. Tick the tabs you want visible, untick the ones to hide.
  3. Click Apply to show/hide tabs immediately and save the choice to a per-user memory file.

Good to know

No Extension/Add-in tabs found means every ribbon tab in the current session matched the built-in ignore list - normal on a install with no other extensions loaded.
Hidden tabs stay hidden only for the current Revit session's ribbon state; reopening Revit shows every tab again until this tool is run to hide them once more.
