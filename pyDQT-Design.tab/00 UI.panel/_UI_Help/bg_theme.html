What it does

Sets the active view's model background colour from a themed picker with a live preview, instead of the blind Black/Gray/White cycle the classic tool used. Pick a ready-made preset, fine-tune with RGB sliders or a HEX value, preview it, then apply.

Workflow

  1. Click a preset button for a one-click colour, or drag the R/G/B sliders, or type a HEX value directly.
  2. Watch the preview swatch update live as you adjust.
  3. Apply sets the active view's background and remembers the choice for next time - the window stays open so you can keep trying colours.
  4. Close exits without discarding whatever was last applied.

Good to know

SHIFT+Click the ribbon button to skip this window entirely and quick-cycle Black → Gray → White → Black, matching the classic tool's behaviour for a fast one-key change.
The last colour applied is remembered and reopened as the starting point next time, so repeat runs don't start from scratch.
