00 UI.panel

What's in this panel

Tools for shaping the Revit UI itself - view background colour, ribbon tab naming, ribbon tab visibility, and checking for extension updates.

Background Theme

Set the model-view background colour from a themed picker with live preview and presets.

Ribbon Name Manager

Shorten or restore Revit ribbon tab names, with an editable, persisted mapping.

Check Update

Compares the installed pyDQT-Design against the latest version on GitHub.

Extension Tab Manager

Show or hide extension/add-in ribbon tabs to declutter the ribbon.
