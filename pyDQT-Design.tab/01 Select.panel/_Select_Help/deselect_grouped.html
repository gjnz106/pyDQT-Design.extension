Deselect Grouped Elements

by Dang Quoc Truong (DQT)

Refine selection

Select Toolset›Deselect Grouped Elements

What it does

Removes every element that belongs to a Group from the current selection, keeping only the loose/ungrouped elements selected. Handy after a window-select that swept up both grouped and ungrouped elements together, when you only want to act on the ungrouped ones.

Workflow

  1. Select a mix of elements - some inside groups, some not.
  2. Run the tool.
  3. Grouped elements are removed from the selection; the result dialog reports how many were removed and how many remain.

Good to know

"Nothing is selected" means the tool needs an active selection to start from - select something first, then run it.
