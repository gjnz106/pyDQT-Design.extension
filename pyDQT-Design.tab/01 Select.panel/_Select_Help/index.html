Select Toolset

by Dang Quoc Truong (DQT)

01 Select.panel

What's in this panel

Tools for finding and selecting elements faster: a searchable element grid, material-based and linked-model selection, filtered picking, sheet-content selection, and six "Select Similar" variants (Type / Family / Category, each in the active view or the whole model).

Quick Select Manager

Searchable, filterable grid of model elements with Zoom/Select/Isolate/Show actions.

Material Select Element

Material usage report, and finds/selects elements using a chosen material.

Select Linked

Selects every element of a chosen Revit Link in the active view at once.

Select By Category

Pick elements while only the categories you chose are selectable.

Select All In-Place Elements

Selects every In-Place family instance, in the view or whole model.

Deselect Grouped Elements

Removes grouped elements from the current selection, keeping the loose ones.

Select on Sheets: DWGs

Selects DWG imports placed directly on chosen sheets.

Select on Sheets: Title Blocks

Selects the title blocks on chosen sheets.

Select Similar: Type (Model)

Improved "Select All Instances: In Model" - multi-seed, handles lines/grids/rooms too.

Select Similar: Type (View)

Same as Type (Model), scoped to the active view.

Select Similar: Family (Model)

Selects every instance of a family (any type) in the whole model.

Select Similar: Family (View)

Same as Family (Model), scoped to the active view.

Select Similar: Category (Model)

Selects every element of a category, any family/type, in the whole model.

Select Similar: Category (View)

Same as Category (Model), scoped to the active view.
