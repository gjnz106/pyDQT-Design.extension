What it does

Two related utilities in one tool: a project-wide material report, and a finder that lists (and can select) every element using a chosen material - instance materials/paint, type materials, and compound wall/floor/roof/ceiling layers are all checked.

Workflow

  1. Run the tool and choose Create Material Report or Find Elements by Material.
  2. Create Material Report prints every material in the model, grouped and counted by category, to the pyRevit output window.
  3. Find Elements by Material lets you pick one material from a list, then shows every element using it (Walls, Floors, Doors, Windows, Structural Framing/Columns, Ceilings, Roofs, Structural Foundations, Generic Models).
  4. Confirm the follow-up prompt to select those elements in the active Revit selection.

Good to know

A material only counts as "used" by the categories this tool checks - it won't catch every possible category in the model, but covers the common architectural/structural ones.
Only works in project documents, not family (.rfa) documents.
