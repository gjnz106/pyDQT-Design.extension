What it does

A searchable, filterable grid of every element in the active view, the whole project, or the current selection - tick the ones you want and jump straight to Zoom To, Select in Model, Isolate, or Show Element, without hunting through the model by hand.

Stat cards

Total Elements
rows currently matching the Display/Filter/Search/Category settings
Checked
rows ticked for the action buttons
Categories
distinct categories among the visible rows
Families
distinct families among the visible rows

Narrowing the list

Display
Active View, Entire Project, or Current Selection - the scope to collect from
Search
matches category, family, type, name/mark, or element ID
Filter By
All Elements / Model Elements / Annotation / MEP Elements / Structural
Category list
click a category to show only that category's rows

Workflow

  1. Pick a Display scope, then narrow with Search / Filter By / Category as needed.
  2. Tick the rows you want, or use Check All / Uncheck All / Invert.
  3. Zoom To frames the first checked (or selected) row in the active view.
  4. Select in Model applies the checked rows as the live Revit selection.
  5. Isolate temporarily isolates the checked rows in the active view.
  6. Show Element uses Revit's own "show element" navigation, falling back to Zoom To.
  7. Refresh re-collects from the model (after moving/deleting elements); Close exits.

Good to know

Double-click a row to zoom to it directly, without checking it first.
Shift+Click / Ctrl+Click in the grid does normal range/multi-select; clicking a checkbox while several rows are selected toggles all of them together.
If Active View returns nothing, the tool automatically retries against the whole project rather than showing an empty grid.
