Select By Category

by Dang Quoc Truong (DQT)

Filtered picking

Select Toolset›Select By Category

What it does

Pick elements in the view while Revit only allows the categories you chose - everything else becomes un-pickable for that pick session. Great for a messy area where you only care about a few categories (e.g. just Walls + Doors, ignoring furniture and annotation).

Workflow

  1. Run the tool.
  2. Tick the categories you want to be selectable, from every real category in the model (plus Grids, Levels and Viewports, which are added even though they're not always "real" model categories).
  3. Click and drag a window, or click elements one by one - only the chosen categories respond; everything else is ignored by the picker entirely.
  4. Press Finish (or Esc to cancel) to apply the picked elements as the active Revit selection.

Good to know

This restricts picking, not visibility - restricted categories are still visible in the view, just unclickable while the picker is active.
