What it does

Selects every In-Place family instance, in the active view or the whole model - handy for finding and cleaning up in-place families, which don't show up in most category-based selection tools the same way loadable families do.

Workflow

  1. Run the tool from any view.
  2. Choose Active View or Whole Model as the search scope.
  3. Every In-Place family instance found in that scope becomes the current selection.

Good to know

"No In-Place elements found" is a normal result on a model that doesn't use in-place families at all.
