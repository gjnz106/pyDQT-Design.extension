Select Linked

Select Toolset›Select Linked

What it does

Selects every model element of a chosen Revit Link in the active view, all at once - normally you can only pick linked elements one at a time (or Tab through overlaps). Useful before a bulk Hide/Unhide/Filter/Isolate action on an entire link.

Workflow

  1. Run the tool from a Plan, Section, Elevation, 3D, Drafting or Sheet view (schedules and browser views aren't supported).
  2. Pick a Revit Link from the list - each entry shows the link instance name and the linked document's title (or <Not Loaded> if it isn't currently loaded).
  3. Every selectable model element of that link, in the active view, becomes the current selection.
  4. From there: right-click > Hide/Unhide in View > Elements, Filter, Tab, Isolate, and so on.

Good to know

A link that shows <Not Loaded> must be reloaded first (Manage > Manage Links) before its elements can be selected.
A handful of linked elements (constraints, internal markers, and a few other non-visual types) can't produce a selectable reference and are silently skipped - the closing report shows how many, if any.
