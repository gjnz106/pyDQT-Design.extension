What it does

Selects the imported/linked DWG elements placed directly on one or more sheets - useful for finding stray CAD artwork or logos pasted onto title sheets, without opening each sheet to look.

Workflow

  1. Select one or more sheets in the Project Browser first, or just run the tool with nothing selected to pick sheets from a list.
  2. Every DWG import placed directly on those sheets becomes the current selection.

Good to know

Only catches DWGs placed directly on the sheet (e.g. a logo dropped straight onto the sheet), not DWGs imported into a view that is then placed in a viewport on the sheet.
