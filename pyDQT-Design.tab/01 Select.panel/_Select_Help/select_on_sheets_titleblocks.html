What it does

Selects the Title Block elements on one or more chosen sheets - useful for a batch title-block swap or parameter edit across many sheets at once.

Workflow

  1. Select one or more sheets in the Project Browser first, or run the tool with nothing selected to pick sheets from a list.
  2. Every title block on those sheets becomes the current selection.

Good to know

Same sheet-picking behaviour as Select on Sheets: DWGs - selection first, list picker as the fallback.
