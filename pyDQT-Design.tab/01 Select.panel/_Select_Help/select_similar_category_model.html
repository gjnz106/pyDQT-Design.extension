What it does

The broadest of the three "Select Similar" tools: select one or more elements, run the tool, and every element sharing the same Category - regardless of family or type - gets selected in the whole model. Use this when you want everything of a kind (e.g. every Door, of every family and type) rather than just matching instances.

Workflow

  1. Select one or more elements anywhere in the model.
  2. Run the tool.
  3. Every element sharing any of the selected elements' categories, across the whole model, is selected.
