Select Similar

Select Toolset›Select Similar: Category (View)

What it does

Same as Select Similar: Category (Model), scoped to the active view instead of the whole model - every element sharing the seed elements' categories, visible in the active view, gets selected.

Workflow

  1. Select one or more elements in the active view.
  2. Run the tool.
  3. Every element sharing those categories, visible in the active view, is selected.

Good to know

Only elements visible in the current view are considered. Use the Model variant for a whole-model sweep.
