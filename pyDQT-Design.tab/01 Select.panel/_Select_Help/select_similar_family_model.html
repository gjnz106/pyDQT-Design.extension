Select Toolset›Select Similar: Family (Model)

What it does

Select one or more instances, run the tool, and every instance belonging to the same Family - across all of that family's Types - gets selected in the whole model. Useful when a family has several types (sizes, styles) and you want every one of them at once, not just the matching type.

Workflow

  1. Select one or more instances anywhere in the model.
  2. Run the tool.
  3. Every instance of that family (any type), across the whole model, is selected.

Good to know

System-family hosts (Walls, Floors, and similar) don't have a meaningful "Family" the same way loadable families do, so seeding with one of these falls back to matching by Category instead.
