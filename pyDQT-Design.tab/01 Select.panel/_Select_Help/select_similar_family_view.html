by Dang Quoc Truong (DQT)

Select Similar

Select Toolset›Select Similar: Family (View)

What it does

Same as Select Similar: Family (Model), scoped to the active view instead of the whole model - every instance of the seed element's family (any type), visible in the active view, gets selected.

Workflow

  1. Select one or more instances in the active view.
  2. Run the tool.
  3. Every instance of that family (any type), visible in the active view, is selected.

Good to know

Only elements visible in the current view are considered. Use the Model variant for a whole-model sweep.
