What it does

An improved version of Revit's built-in "Select All Instances: In Model". Select one or more elements, run the tool, and every element sharing the same Type anywhere in the model gets selected - including unusual elements the built-in tool ignores (Lines, Grids, Levels, Rooms, Areas, Scope Boxes, Reference Planes, and more).

How it differs from Revit's built-in tool

Revit's "Select All Instances"Select Similar: Type
Multiple seed elements at onceNo - one at a timeYes
Lines, Grids, Levels, Rooms, Areas, Scope BoxesNot supportedMatched by category as a smart fallback
ScopeIn Model / In View (built-in menu split)Model (this page) or View (see the other tool)

Workflow

  1. Select one or more instances anywhere in the model.
  2. Run the tool.
  3. Every instance of the same Type, across the whole model, is selected.

Good to know

Elements with no meaningful "Type" (lines, grids, levels, rooms, areas, scope boxes, reference planes, and similar) are matched by Category instead, so seeding with one of these still works as expected.
