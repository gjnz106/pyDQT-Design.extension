Align Grids

by Dang Quoc Truong (DQT)

Grids & levels

Modify Toolset›Align Grids

What it does

Aligns grid start/end 2D extents to a reference element (Grid, Detail Line, Model Line, or Reference Plane) - useful for snapping a batch of grids to a consistent extent line instead of dragging each one.

Workflow

  1. Choose which end(s) to align: Start (Bubble End), End (Non-Bubble), or Both (picks 2 references).
  2. Click Run Alignment.
  3. Select the grids to align (Enter/Right-click to finish).
  4. Pick the reference element - the grid endpoint snaps to its line.

Good to know

Force 2D extent switches the grid to a view-specific 2D extent before aligning, if it isn't already - needed because a 3D-extent grid's endpoint is shared across every view and can't be aligned independently in just one.
