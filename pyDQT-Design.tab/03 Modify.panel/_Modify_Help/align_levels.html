Align Levels

by Dang Quoc Truong (DQT)

Grids & levels

Modify Toolset›Align Levels

What it does

Aligns level start/end 2D extents to a reference element (Level, Detail Line, Model Line, Reference Plane, or Grid) - the level equivalent of Align Grids.

Workflow

  1. Choose which end(s) to align: Left (Bubble End), Right (Non-Bubble), or Both (picks 2 references).
  2. Click Run Alignment.
  3. Select the levels to align (Enter/Right-click to finish).
  4. Pick the reference element - the level endpoint snaps to its line.

Good to know

Force 2D extent switches the level to a view-specific 2D extent before aligning, if it isn't already.
