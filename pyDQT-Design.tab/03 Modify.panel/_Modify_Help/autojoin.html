Auto Join Elements

by Dang Quoc Truong (DQT)

Element joins

Modify Toolset›Auto Join Elements

What it does

Joins or unjoins elements in the active view using rule-based category pairs, instead of picking pairs one at a time. Each rule defines a Priority Category and a Join With Category - the Priority Category cuts the other one, matching Revit's own join direction semantics.

Workflow

  1. Add one or more rules (category pairs) with Add Rule; the Switch button on a rule swaps which side cuts which.
  2. Tick Selected elements only to restrict Join/Unjoin to the current Revit selection instead of the whole active view.
  3. Join applies every enabled rule; Unjoin removes those joins.
  4. Save Setting / Delete Setting keep named rule sets, picked from the dropdown, for reuse across sessions.

Good to know

Rules only run against elements of the categories they name - there's no need for a rule matching every category pair in the model, just the ones that actually need joining.
