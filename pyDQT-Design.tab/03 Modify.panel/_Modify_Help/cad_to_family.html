CAD to Family

by Dang Quoc Truong (DQT)

CAD

Modify Toolset›CAD to Family

What it does

Turns a 3D CAD import (DWG, DXF, SAT, SKP...) into a loadable Generic Model family and places it exactly where every copy of the CAD is - same point, turned the same way.

The CAD's 3D geometry is rebuilt as native Revit geometry, so the result is a real family you can schedule, give a material, cut and join - and the imported CAD can go. One family is made per CAD file, so a hundred copies of the same block (armour units, precast pieces, equipment) become one family with a hundred instances.

Workflow

  1. Select the CAD import(s) - or run the tool with nothing selected and pick one. Several CAD files can be selected at once.
  2. Click CAD to Family. The dialog shows, for each CAD file, how many copies are selected and how many are in the project.
  3. Choose All copies in the project or Only the selected. Tick Delete the CAD once the families are placed to remove the imports in the same step (Undo brings them back).
  4. The families are built, loaded and placed in one step you can Undo. The new Generic Models are selected, and a summary says what each family is made of.

What you get

Family
named after the CAD file without its extension - xblocplus_0.5m3.dwg → xblocplus_0.5m3 (v2 when that name is taken). Project Browser › Families › Generic Models
Instances
one per 3D copy of the CAD, at the same point and turned the same way in plan
Family origin
the bottom centre of the CAD geometry - not the DWG's origin, so a drawing far from its origin still gives a compact family
Material
a Material type parameter drives every solid form - set it once for all instances
Level / Workset
the CAD's level (else the level at or below it) and the CAD's workset
Comments
names the CAD copy each instance replaces

How the geometry is rebuilt

CAD solids
3D solids (ACIS) become solid Freeform forms
Closed meshes
the triangles of a polyface / mesh body are turned into a solid first, then into a solid form. Loose 3D faces (one face each) are joined up and closed into a solid when they enclose a volume
Open meshes
a mesh that does not enclose a volume cannot be a solid: it is kept as mesh geometry (a DirectShape) inside the family, so the shape stays complete. It shows and prints, but cannot be cut or joined and takes no material
Lines
2D lines and curves are not part of the family. A CAD with only lines is refused

Blocks inside the CAD (blocks within blocks too) are opened up and placed where they are in the drawing.

Good to know

Tilted, mirrored or scaled copies. A Generic Model can only be turned in plan. A copy of the CAD that is tilted, mirrored or scaled in 3D gets a family of its own with that orientation built in, named <name> (tilted 1), (tilted 2)... - it still lands exactly where the CAD is.
Deleting the CAD. With the option ticked, every converted copy is deleted, and the CAD import type too when no copy of it is left (so it does not stay behind as an unused CAD type that Model Health Check counts as a CAD import). A 2D, view-specific copy of the same CAD is never converted and keeps the type.
The family is a snapshot of the CAD: re-importing a changed DWG does not update it. Run the tool again on the new import - the new family is named with a v2 suffix - and delete the old one.
The tool needs Revit's Metric Generic Model.rft family template. It finds it by itself under the family-template folder set in Options › File Locations (or the standard install folder); if it cannot, it asks you to browse to it.
Works on 3D CAD imports and links in the active model. A 2D, view-specific CAD has no 3D geometry and cannot be picked. A very large or detailed CAD takes longer to rebuild; if Revit refuses all of its geometry the tool says so and changes nothing.
