CAD to Floor / Part

by Dang Quoc Truong (DQT)

CAD conversion

Modify Toolset›CAD to Floor / Part

What it does

Creates Revit Floor or Part (DirectShape) elements from linked or imported AutoCAD DWG geometry - turns closed CAD polylines on chosen layers directly into real Revit elements.

Workflow

  1. Pick a CAD import/link in the model.
  2. Scan Layers lists every layer found in that CAD file.
  3. Tick the layers to convert - Select All / Select None help with long lists.
  4. Choose Floor or Part mode.
  5. Create Floors (or Create Parts, depending on mode) builds the elements.
  6. Refresh re-scans after picking a different CAD file.
