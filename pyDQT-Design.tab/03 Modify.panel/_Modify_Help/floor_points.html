Floor Points

by Dang Quoc Truong (DQT)

Slab shape editing

Modify Toolset›Floor Points

What it does

Bulk-adjusts the slab shape points ("Modify Sub Elements") of one or more selected floors or toposolids at once - offset every point by a delta, or flatten them all onto one elevation, instead of dragging each point by hand.

Options

Points to move
All points / Interior points only (added inside the slab) / Boundary points only (on the sketch outline)
Offset
move each selected point by a value (e.g. -2000 mm)
Set
put every selected point on one elevation

Workflow

  1. Select one or more floors/toposolids before running the tool.
  2. Choose which points to move and whether to Offset or Set.
  3. Enter the value (mm); the Result box previews what will change.
  4. Click Apply.
