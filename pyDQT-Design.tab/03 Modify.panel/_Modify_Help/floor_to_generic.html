Floor to Generic Model

by Dang Quoc Truong (DQT)

Floors

Modify Toolset›Floor to Generic Model

What it does

Creates a Generic Model with exactly the shape of each selected floor. The copy is taken from the floor's finished solid geometry, so a sloped or shape-edited floor, a floor with openings and a floor trimmed by joined walls all come out the same - not a rebuilt outline.

Workflow

  1. Select one or more floors - or run the tool with nothing selected and pick them, then click Finish.
  2. Click Floor to Generic. One Generic Model is created for each floor, exactly on top of it, in a single step you can Undo.
  3. The new Generic Models are selected, so you can move them away, or hide the original floor to see them.

What you get

Category
Generic Models (a DirectShape, not a loadable family)
Type
one per floor type, named Floor Copy - <floor type>, so copies can be scheduled and filtered by the floor type they came from
Comments
says which floor it was copied from (type and id)
Mark
carried over from the floor when it has one

Good to know

The copy is a snapshot. It does not follow the floor if the floor is edited later - copy it again (the tool asks what to do about floors that already have a copy) and delete the old one.
Floors that already have a copy made by this tool are noticed. You choose to skip them or copy them again, so you do not end up with two copies stacked on the same floor by accident.
Works on floors in the active model. Floors inside a linked model, and toposolids, are not copied. A floor Revit gives no solid for, or whose geometry a Generic Model cannot hold, is listed as not copied and the other floors still go.
