Floor to Generic

by Dang Quoc Truong (DQT)

Floors

Modify Toolset›Floor to Generic

What it does

Turns the selected floors into a Model In-Place (Generic Models) with exactly the floors' shape - an in-place family of the project. Unlike a floor, a Model In-Place can be joined or cut with a toposolid.

The shape is taken from the floor's finished solid geometry, so a sloped or shape-edited floor, a floor with openings and a floor trimmed by joined walls all come out the same - not a rebuilt outline.

Workflow

  1. In the project, select one or more floors - or run the tool with nothing selected and pick them, then click Finish.
  2. Click Floor to Generic. A temporary family opens with the floor shape already selected (one solid form per floor solid).
  3. Press Ctrl+C.
  4. Go back to the project (its tab, or View › Switch Windows).
  5. Architecture › Component › Model In-Place: pick Generic Models and give it a name (the tool suggests Floor Copy - <floor type>).
  6. Modify › Paste › Aligned to Same Place - the shape lands exactly on the floor.
  7. Finish Model. Close the temporary family - no need to save it.
  8. Join or cut the toposolid with the new Model In-Place.

What you get

Element
a Model In-Place of the category you pick (Generic Models), with the floor's shape as solid forms
Position
exactly on the floor - the forms keep the floor's coordinates
Several floors
go into one Model In-Place together; run the tool once per floor if you want one each
Temporary family
DQT Temp - Floor Copy - ...rfa in the Windows temp folder; the tool clears old ones on its next run

Good to know

Why there are manual steps. Revit's API cannot create a Model In-Place, and add-in buttons are locked while the Model In-Place editor is open - no add-in can build one by itself. So the tool prepares the exact shape and Revit's own Copy / Paste puts it into the in-place family.
Use Paste › Aligned to Same Place, not a plain Ctrl+V - a plain paste puts the shape wherever you click. Run the tool again while the temporary family is active to select its forms and see the steps again.
The tool needs Revit's Metric Generic Model.rft family template for the temporary family. It finds it by itself under the family-template folder set in Options › File Locations (or the standard install folder); if it cannot, it asks you to browse to it.
The copy is a snapshot. It does not follow the floor if the floor is edited later - copy it again and delete the old Model In-Place. Material is not copied: the forms use By Category; set one in the in-place editor (select the forms › Properties › Material).
Works on floors in the active model. Floors inside a linked model, and toposolids, are not copied. A floor Revit gives no solid for, or whose geometry a family form cannot hold, is listed as not copied and the other floors still go. The original floor is left as it is - hide or delete it yourself.
