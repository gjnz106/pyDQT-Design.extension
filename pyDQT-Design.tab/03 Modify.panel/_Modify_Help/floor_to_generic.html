Floor to Generic Model

by Dang Quoc Truong (DQT)

Floors

Modify Toolset›Floor to Generic Model

What it does

Turns each selected floor into a Generic Model family placed exactly where the floor is, with exactly the floor's shape. A floor cannot be joined or cut with a toposolid; a family instance can - so this gives you a copy of the floor you can join to, or cut, the toposolid.

The shape is taken from the floor's finished solid geometry, so a sloped or shape-edited floor, a floor with openings and a floor trimmed by joined walls all come out the same - not a rebuilt outline.

Workflow

  1. Select one or more floors - or run the tool with nothing selected and pick them, then click Finish.
  2. Click Floor to Generic. A small family is built for each floor, loaded into the project and placed exactly on top of the floor, all in one step you can Undo. It takes a moment per floor.
  3. The new Generic Models are selected, so you can move them away, or hide the original floor to see them.
  4. Join or cut the toposolid with the new Generic Model as you would with any other family instance.

What you get

Element
a Generic Models family instance, with the floor's shape as a solid form
Family
one per floor, named Floor Copy - <floor type> (floor <id>) - see Project Browser › Families › Generic Models
Level
the floor's own level
Comments
says which floor it was copied from (type and id)
Mark
carried over from the floor when it has one

Good to know

This is a family, not a Model In-Place. Revit's API cannot create a Model In-Place - that editor is user interface only - so the tool builds a Generic Model family instead. It behaves like a Model In-Place for joining and cutting, but it is not "in place": tools that look for in-place families (Select In-Place Elements, In-Place Volume) will not see these copies.
The tool needs Revit's Metric Generic Model.rft family template to build each family. It finds it by itself under the family-template folder set in Options › File Locations (or the standard install folder); if it cannot, it asks you to browse to it.
The copy is a snapshot. It does not follow the floor if the floor is edited later - copy it again (the tool asks what to do about floors that already have a copy: skip them, or copy them again) and delete the old one. A repeated copy is named with a v2, v3... suffix.
Material is not copied: the new form uses the Generic Models default (By Category). Change it in the family or with Paint if you need it.
Works on floors in the active model. Floors inside a linked model, and toposolids, are not copied. A floor Revit gives no solid for, or whose geometry a family form cannot hold, is listed as not copied and the other floors still go.
