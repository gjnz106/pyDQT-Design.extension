Modify Toolset›Grid Swap

What it does

Swaps gridlines between 3D (whole-model) and 2D (view-specific) extents, and controls bubble visibility, across multiple views at once - a batch version of right-clicking a grid and choosing "2D Extents" / "3D Extents" one at a time.

Grid columns / stats

Total Grids
grids found in the chosen view scope
Is 3D
grids currently using a 3D (whole-model) extent
Is 2D
grids currently using a 2D (view-specific) extent

Workflow

  1. Pick the view to work in, and filter/search the grid list if needed.
  2. Use Select All / None / 3D / 2D to check the rows to act on.
  3. Swap to 2D / Swap to 3D changes the checked grids' extent type.
  4. Toggle flips each checked grid between 2D and 3D.
  5. The Bubble row (Start/End/All, ON/OFF) shows or hides the datum bubble on that end, for the checked grids.
  6. Refresh re-scans the model after any change made outside this tool.
