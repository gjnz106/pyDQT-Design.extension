Modify Toolset

by Dang Quoc Truong (DQT)

03 Modify.panel

What's in this panel

20 tools for bulk-editing model geometry and datums: steel coping and joins, CAD-to-native conversion, floor shape points, grid/level alignment and extent swapping, level-change impact analysis and rehosting, a property-line drafter, base-level revision, room-to-area conversion, five element-splitting tools, and a linked-model wall- opening cutter.

Auto Coping

Batch apply or remove coping on steel beams.

Auto Join Elements

Join/unjoin elements in the active view using rule-based category pairs.

CAD to Floor / Part

Create Revit Floors or Parts from linked/imported CAD layers.

CAD to Wall

Convert CAD lines to Revit Walls, auto-creating wall types by detected thickness.

Floor Points

Bulk-adjust floor/toposolid shape points - offset or flatten to one elevation.

Align Grids

Align grid 2D extents to a reference element.

Grid Swap

Swap gridlines between 3D/2D extents and control bubble visibility, in batch.

Align Levels

Align level 2D extents to a reference element.

Level Swap

Swap levels between 3D/2D extents and control bubble visibility, in batch.

Level Impact

Simulate a Level elevation change to see which elements would move, non-destructively.

Rehost Level

Move all elements from one level onto another without changing position or shape.

Property Line from Excel

Draw a closed Model Line boundary from coordinate tables in an Excel file.

Revise Base

Change the base/reference level of many elements while keeping their position.

Room To Area

Auto-create Areas from selected Rooms with matching boundary lines.

Split Ceiling

Split a ceiling with disconnected boundaries into separate ceilings.

Split Columns

Split one structural column at chosen levels, with a hosted-elements report.

Split Floor

Split a floor with disconnected boundaries into separate floors.

Split Shaft Opening

Survey and split multi-region shaft openings, preserving symbolic lines and holes.

Split Walls

Split one or more walls at chosen levels, preserving hosted elements.

Wall Profile Cut from Link

Create wall openings wherever they intersect elements from a linked model.
