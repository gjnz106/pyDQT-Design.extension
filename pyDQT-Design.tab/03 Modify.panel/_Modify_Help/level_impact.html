What it does

Answers "if I change this Level's elevation, which elements move with it?" before you actually do it. The change is simulated inside a transaction that is always rolled back - nothing in the model is modified.

How it works

Each model element's bounding box (Z) is recorded, the level's elevation is bumped by the requested amount, the document is regenerated so Revit's own constraint solver runs, and each element's Z is measured again. Because it uses Revit's real regeneration rather than reimplementing the hosting rules, it catches indirect dependencies too.

Moves with level
the whole element shifted by the full amount (its elevation is driven by this level - e.g. a floor, a wall based here, a column based here, furniture hosted here)
Partially affected
only part of it moved (e.g. a wall whose BASE is on this level but TOP is on another - it gets taller/shorter, not just moved)

Workflow

  1. Pick the Level and the elevation change (mm, + = up).
  2. Choose Scope: the entire model, or just the current selection.
  3. Check Impact reports the per-category breakdown and selects the affected elements in the model so you can see exactly what would move.
