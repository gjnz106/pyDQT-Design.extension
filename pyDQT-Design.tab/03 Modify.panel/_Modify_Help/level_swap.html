Level Swap

Grids & levels

Modify Toolset›Level Swap

What it does

Swaps levels between 3D (whole-model) and 2D (view-specific) extents, and controls bubble visibility, across multiple views at once - the level equivalent of Grid Swap.

Workflow

  1. Pick the view to work in, and filter/search the level list if needed.
  2. Use Select All / None / 3D / 2D to check the rows to act on.
  3. Swap to 2D / Swap to 3D changes the checked levels' extent type.
  4. Toggle flips each checked level between 2D and 3D.
  5. The Bubble row (Left/Right/All, ON/OFF) shows or hides the datum bubble on that end, for the checked levels.
  6. Refresh re-scans the model after any change made outside this tool.
