Split MEP at Wall

by Dang Quoc Truong (DQT)

Split tools

Modify Toolset›Split MEP at Wall

What it does

Splits duct, pipe, cable tray, and conduit runs in this document wherever they physically cross a wall in a selected linked model - each run is broken into two elements at the point where its centerline crosses the wall's solid geometry, ready for sleeves, firestopping, or per-side scheduling.

Layout

Linked model
the link whose walls are used as the cut source; the badge shows how many walls it has
Categories
Ducts, Pipes, Cable Trays, Conduits - tick which ones to check
Active view only
unticked (default) scans the whole document; ticked limits the scan to elements visible in the active view

Workflow

  1. Pick the linked model that holds the walls to split against.
  2. Tick the categories to check.
  3. Optionally tick Active view only to limit the scope.
  4. Split at Wall scans every straight run of the ticked categories, finds every linked wall it physically crosses, and breaks the run into two elements at each crossing.
  5. The status panel reports how many runs were split (and into how many pieces), and why any were skipped.

Good to know

Only straight sections are supported - a run with a curved (non-straight) centerline is skipped and counted separately in the results. Flex duct/pipe aren't offered, for the same reason.
A run that already has a modeled opening/sleeve where it meets the wall correctly reports no crossing there, since the split is based on the wall's actual solid geometry, not just its bounding box.
A crossing within ~50mm of the run's own end is skipped rather than cut - breaking that close to an end is a known way to destabilize Revit's native break-curve API, not just this tool.
Looking for the inverse operation - cutting the wall instead of the MEP element - see Wall Profile Cut from Link.
