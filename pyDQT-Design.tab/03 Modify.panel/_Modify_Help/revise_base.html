Revise Base

by Dang Quoc Truong (DQT)

Levels & constraints

Modify Toolset›Revise Base

What it does

Changes the base/reference level of many elements at once and keeps their absolute position by automatically compensating the offset. Supports Walls, Floors, Columns, Structural Columns, Beams, Structural Framing, Doors, and Windows.

Doors and Windows

For Doors/Windows, "Level" (Schedule Level) and "Sill Height" stand in for Base Constraint/Offset. A hosted door or window whose family/type has no Sill Height parameter is reported as failed rather than silently skipped, and the Level change is verified after Revit regenerates - since a host wall can silently reset a door or window's Level back to its own, any element where that happens is also reported as failed rather than counted as a success.

Workflow

  1. Select the elements to revise.
  2. Run the tool.
  3. Select the new base/reference level from the list.
  4. The tool updates the level and compensates the offset for each element, then reports exactly which elements succeeded and which failed (and why) - it never just shows a bare success/failure count.
