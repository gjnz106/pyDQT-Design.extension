Room To Area

by Dang Quoc Truong (DQT)

Rooms & areas

Modify Toolset›Room To Area

What it does

Automatically creates Areas from selected Rooms - draws area boundary lines matching each room's boundary and places the Area element, instead of tracing area boundaries by hand.

Workflow

  1. The grid lists candidate rooms - use Check All / Uncheck All / Invert to manage which are included.
  2. Select in Revit selects the checked rooms in the model, to verify you have the right ones.
  3. Pick the target area scheme and area plan view; tick Auto-create Area Plan if missing to have the tool create the view automatically when the chosen scheme has none.
  4. Tick which room parameters to carry over under Transfer Parameters (All/None).
  5. Create from Checked processes every checked room; Create from Selected processes only the rooms currently selected in the grid.
