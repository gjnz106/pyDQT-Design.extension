Split Ceiling

by Dang Quoc Truong (DQT)

Split tools

Modify Toolset›Split Ceiling

What it does

Splits a ceiling with multiple disconnected boundary loops (drawn as one sketch but really several separate regions) into separate individual ceiling elements - one per disconnected boundary.

Workflow

  1. Run the tool and confirm to start picking.
  2. Select the ceiling(s) to split (Esc or Finish when done) - only Ceiling elements are accepted, everything else is skipped.
  3. Each disconnected boundary loop becomes its own new ceiling; a summary reports how many were created.
