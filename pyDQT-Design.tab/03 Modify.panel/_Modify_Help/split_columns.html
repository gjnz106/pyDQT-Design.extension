Split Columns

by Dang Quoc Truong (DQT)

Split tools

Modify Toolset›Split Columns

What it does

Splits one structural column at chosen levels - e.g. a column that runs through several floors becomes one column segment per level range - and reports any elements hosted on the original column so nothing gets lost in the split.

Workflow

  1. Select exactly one structural column, then run the tool.
  2. If the column has hosted elements, a warning lists them and offers to export a CSV report before continuing (for manual recreation afterward, since a split column can't carry them automatically).
  3. Pick the level(s) to split at from the list.
  4. Confirm to split the column into segments at those levels.

Good to know

Only one column at a time is supported - selecting more than one, or selecting a non-structural-column element, is rejected with an explanatory message.
