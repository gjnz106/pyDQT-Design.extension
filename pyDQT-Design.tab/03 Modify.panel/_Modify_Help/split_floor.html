Split Floor

by Dang Quoc Truong (DQT)

Split tools

Modify Toolset›Split Floor

What it does

Splits a floor with multiple disconnected boundary loops into separate individual floor elements - one per disconnected boundary, matching Split Ceiling's approach but for floors.

Workflow

  1. Run the tool and confirm to start picking.
  2. Select the floor(s) to split (Esc or Finish when done).
  3. Each disconnected boundary loop becomes its own new floor; a summary reports how many were created.

Good to know

A floor with modified vertices (height adjustments / a sloped slab) triggers a warning before splitting: the tool tries to re-apply those point modifications to the new floors by matching vertices, but the result can be imperfect - verify the elevations afterward.
