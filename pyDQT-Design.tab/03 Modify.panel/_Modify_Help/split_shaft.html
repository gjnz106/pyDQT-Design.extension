Split Shaft Opening

by Dang Quoc Truong (DQT)

Split tools

Modify Toolset›Split Shaft Opening

What it does

Splits a shaft opening that has several disconnected boundary loops into separate individual shaft openings, using a copy-paste method that preserves the opening's Symbolic Lines and holes natively instead of redrawing them as detached model lines.

Workflow

  1. Choose how to pick openings: whole model, active view, current selection, or pick in view.
  2. The tool surveys the openings first (read-only, no transaction) and reports how many separate regions each one actually contains - a shaft that looks like one element in the browser is often a dozen regions in one sketch, with no native way to see that count otherwise.
  3. Tick which multi-region openings to split, biggest first.
  4. The tool copy-pastes the shaft one copy at a time, reduces each copy to its one region immediately, and reduces the original opening last (so if anything fails mid-run, the original is still untouched).

Good to know

Splitting uses SketchEditScope.Commit() on a shaft opening sketch, which is unstable on some Revit builds and can hard- crash Revit (an unrecoverable native crash Python cannot catch). Save the model before running this tool.
The survey step alone is always safe to run - it opens no transaction and changes nothing, so use it just to see the region count even if you don't intend to split anything yet.
