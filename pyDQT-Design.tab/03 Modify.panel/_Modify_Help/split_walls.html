Split Walls

by Dang Quoc Truong (DQT)

Split tools

Modify Toolset›Split Walls

What it does

Splits one or more walls at chosen levels - unlike Split Columns, multiple walls can be selected and processed in the same run - while preserving doors, windows, and other hosted elements on the correct resulting wall segment.

Workflow

  1. Select one or more walls, then run the tool.
  2. Pick the level(s) to split at from the list.
  3. Confirm to split every selected wall into segments at those levels; hosted doors, windows, and similar elements stay attached to whichever new segment they actually sit on.
