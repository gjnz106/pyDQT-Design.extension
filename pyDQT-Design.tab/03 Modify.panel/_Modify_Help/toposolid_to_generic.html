Toposolid to Generic

by Dang Quoc Truong (DQT)

Site

Modify Toolset›Toposolid to Generic

What it does

Creates a Generic Model with exactly the shape of one toposolid, placed exactly where the toposolid is.

The shape is taken from the toposolid's finished solid geometry - its sloped, sculpted top included - not a rebuilt outline. It lives in a small loadable Generic Model family as a solid form.

Workflow

  1. Select one toposolid - or run the tool with nothing selected and pick it. (With several selected, the tool asks you to pick one.)
  2. Click Toposolid to Generic. The family is built, loaded and placed on the toposolid in one step you can Undo. The new Generic Model is selected - hide the toposolid to see it.

What you get

Element
a Generic Models family instance with the toposolid's shape as a solid form
Family
Toposolid Copy - <toposolid type> (toposolid <id>) - see Project Browser › Families › Generic Models
Position
exactly on the toposolid; on the toposolid's level when it has one
Comments
says which toposolid it was copied from (type and id)
Mark
carried over from the toposolid when it has one

Good to know

Why a solid, not a void. The first version made the form a void and failed in Revit with can't assign to read-only property IsSolid: Revit's API does not let an add-in turn a Freeform form into a void. The copy is now a solid Generic Model.
The copy is a snapshot. It does not follow the toposolid if the toposolid is edited later - run the tool again (it asks before making a second copy of the same toposolid, named with a v2 suffix) and delete the old one.
Material is not copied: the form uses the Generic Models default (By Category). Change it in the family or with Paint if you need it.
The tool needs Revit's Metric Generic Model.rft family template. It finds it by itself under the family-template folder set in Options › File Locations (or the standard install folder); if it cannot, it asks you to browse to it.
Works on toposolids (Revit 2024 and later) in the active model, one at a time. A toposolid inside a linked model is not copied. A very large or detailed toposolid takes longer, and if Revit refuses its geometry as a family form the tool says so and changes nothing.
