Toposolid to Void

by Dang Quoc Truong (DQT)

Site

Modify Toolset›Toposolid to Void

What it does

Creates a void Generic Model with exactly the shape of one toposolid, placed exactly where the toposolid is. Use it with Modify › Cut Geometry to cut other elements wherever they run into the terrain.

The shape is taken from the toposolid's finished solid geometry - its sloped, sculpted top included - not a rebuilt outline. The void lives in a small loadable Generic Model family with Cut with Voids When Loaded already turned on, so it is ready to cut.

Workflow

  1. Select one toposolid - or run the tool with nothing selected and pick it. (With several selected, the tool asks you to pick one.)
  2. Click Toposolid to Void. The family is built, loaded and placed on the toposolid in one step you can Undo. The new void is selected.
  3. Modify › Cut Geometry: click the element to cut, then click the void. Repeat for every element to cut.

What you get

Element
a Generic Models family instance whose only geometry is an unattached void with the toposolid's shape
Family
Toposolid Void - <toposolid type> (toposolid <id>) - see Project Browser › Families › Generic Models
Cut with Voids When Loaded
on
Position
exactly on the toposolid; on the toposolid's level when it has one
Comments
says which toposolid it was copied from (type and id)
Mark
carried over from the toposolid when it has one

Good to know

A void family cuts nothing on its own - each cut is made with Cut Geometry (element first, then the void). Revit lets a loaded family's void cut walls, floors, roofs, ceilings, structural framing, columns and foundations, and generic models. Use Uncut Geometry to take a cut off again.
An unattached void shows in views as a see-through shape you can click. Once your cuts are made you can hide it (Hide in View › Elements): the cuts stay.
The void is a snapshot. It does not follow the toposolid if the toposolid is edited later - run the tool again (it asks before making a second void for the same toposolid, named with a v2 suffix), redo the cuts with the new void and delete the old one.
The tool needs Revit's Metric Generic Model.rft family template. It finds it by itself under the family-template folder set in Options › File Locations (or the standard install folder); if it cannot, it asks you to browse to it.
Works on toposolids (Revit 2024 and later) in the active model, one at a time. A toposolid inside a linked model is not copied. A very large or detailed toposolid takes longer, and if Revit refuses its geometry as a family form the tool says so and changes nothing.
