What it does

Creates openings in walls wherever they intersect elements (ducts, pipes, structural framing, and so on) from a linked model - a batch coordination tool for cutting MEP/structural clashes into hosted walls, using pyRevit's own dialogs only (no custom WPF window).

Workflow

  1. Pick the Revit Link to check against.
  2. Pick the categories to scan in that link (ducts, pipes, framing, etc).
  3. Choose which walls to check: All Walls in Active View, or Pick Walls Manually.
  4. The tool scans for intersections and lists every one found; tick which ones to actually cut.
  5. Choose the opening method: Wall Opening (recommended), Edit Wall Profile, or Place Opening Family (pick a family/type if chosen).
  6. Enter an offset (mm) - a buffer added around each intersecting element - then the tool creates the openings and reports how many succeeded.

Good to know

If Edit Wall Profile fails for a given intersection, the tool automatically falls back to the Wall Opening method for that one instead of just reporting a failure.
