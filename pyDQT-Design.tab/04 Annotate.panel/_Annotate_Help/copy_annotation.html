Copy Annotations Between Models

by Dang Quoc Truong (DQT)

Annotation transfer

Annotate Toolset›Copy Annotations Between Models

What it does

Transfers dimensions, tags, text notes, and detail components from matched views in a source document to a destination document - useful when a linked/central model split leaves annotation stranded in the wrong file, or a coordination model needs another model's view markup.

Workflow

  1. Pick the Source and Destination document (from any currently open Revit document) - Swap flips the two.
  2. Tick the categories to copy - All / None helpers included.
  3. Tick the source views to scan, then Scan Annotations in Selected Views to see how many annotations were found per matched destination view.
  4. Copy Annotations transfers them, view by matched view.

Good to know

Source and Destination must be different open documents - the tool refuses to run otherwise.
