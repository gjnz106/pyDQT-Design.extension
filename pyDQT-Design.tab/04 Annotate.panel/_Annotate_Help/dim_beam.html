Auto Dimension Beams

Auto dimension

Annotate Toolset›Auto Dimension Beams

What it does

Auto-dimensions the selected beams (any angle) in the active plan view, without manually clicking each face/grid pair.

Dimension modes (tick any combination)

1. Beam Size
width (side to side)
2. Face to Grid
beam side face to the nearest parallel grid
3. Center to Grid
beam centreline to the nearest parallel grid
4. End to Grid
each beam end to the nearest perpendicular grid

Workflow

  1. Select the beams to dimension in a plan view, then run the tool.
  2. Pick a Dimension Type (or leave <Default>).
  3. Tick the dimension mode(s) needed.
  4. Set the dim line offset (mm) and optionally tick 'Avoid overlapping existing dimensions / tags / text'.
  5. Click Create Dimensions.
