Auto dimension

Annotate Toolset›Auto Dimension Columns

What it does

Auto-dimensions the selected columns in the active plan view - the column equivalent of Auto Dimension Beams.

Dimension modes (tick any combination)

1. Column Size
Width (Left-Right) and/or Depth (Front-Back)
2. Face to Nearest Grid
X-direction (face to vertical grid) and/or Y-direction (face to horizontal grid)
3. Center to Nearest Grid
same, from the column centerline

Workflow

  1. Select the columns to dimension in a plan view, then run the tool.
  2. Pick a Dimension Type (or leave <Default>).
  3. Tick the dimension mode(s) needed.
  4. Set the dim line offset (mm) and optionally tick 'Avoid overlapping existing dimensions / tags / text'.
  5. Click Create Dimensions.
