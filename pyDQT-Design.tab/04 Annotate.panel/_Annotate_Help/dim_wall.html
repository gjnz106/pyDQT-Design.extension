Annotate Toolset›Wall Dimensioning

What it does

Simple, safe auto-dimensioning for walls - select walls and it creates a dimension chain between wall faces (or other references, depending on mode). Works in Floor Plan or Section views.

Modes (tick any combination)

Wall Faces
chain between parallel walls' faces
Wall Thickness
each wall dimensioned individually
Wall Thickness + Nearest Grid
thickness plus a reference to the nearest grid
Wall Center to Nearest Grid
wall centerline to the nearest grid
Linked Wall Thickness + Nearest Grid
same, for walls in a linked model

Workflow

  1. Open a Floor Plan or Section view.
  2. Run the tool and tick the mode(s) to create.
  3. For host-wall modes: select walls first, or pick them when prompted.
  4. Enter the offset distance (mm) for the dimension line.
