Annotate Toolset

04 Annotate.panel

What's in this panel

10 tools for annotation work: cross-document annotation transfer, auto-dimensioning for beams/columns/walls, snap-to-grid cleanup for dimensioned offsets, fill-region merging and creation, spline-based renumbering, tag rotation to match a grid, and a tag-completeness checker.

Copy Annotations Between Models

Transfer dims, tags, text notes and details across open documents.

Auto Dimension Beams

Auto-dimension selected beams (any angle) in the active plan view.

Auto Dimension Columns

Auto-dimension selected columns in the active plan view.

Wall Dimensioning

Simple, safe auto-dimensioning for walls.

Snap to Grid

Nudge elements so their offset to a grid becomes a clean round number.

Merge Fill Region

Merge several filled regions in the view into one.

Renumber Along Spline

Renumber a category's elements by their order along a picked curve.

Rotate Tag to Grid

Rotate selected tags to match a picked grid's direction.

Tag Checker

Find untagged elements and flag far-away or broken ("?") tags.

Wall Fill Region

Create filled regions covering walls/columns, from host or linked models.
