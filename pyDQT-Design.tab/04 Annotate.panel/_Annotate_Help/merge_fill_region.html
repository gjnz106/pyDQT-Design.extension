Merge Fill Region

by Dang Quoc Truong (DQT)

Fill regions

Annotate Toolset›Merge Fill Region

What it does

Merges several filled regions in the active view into a single filled region, using the first selected region's type. Boundaries are extruded along the view direction and unioned, then the merged outline is read back from the solid - so it works in any view orientation (plan / section / elevation), keeps holes, and cleans up collinear/short edges.

Workflow

  1. Select at least 2 filled regions in the active view.
  2. Run the tool.
  3. The regions are merged into one, using the first selected region's type; the original regions are deleted only after the merged one is successfully created.
