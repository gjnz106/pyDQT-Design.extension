Rotate Tag to Grid

by Dang Quoc Truong (DQT)

Tags

Annotate Toolset›Rotate Tag to Grid

What it does

Rotates the selected tag(s) to match the direction of a grid picked from the active view - lines up tag text with the drawing's grid orientation instead of leaving it at Revit's default angle.

Workflow

  1. Select the tag(s) to rotate, then run the tool.
  2. Pick which grid direction to rotate to from the dropdown - only straight grids drawn in the current view are listed, each with the angle it will apply.
  3. 'Keep tag text upright' avoids an upside-down result.
  4. Click Rotate.

Good to know

Tags switch to "Rotate with component" orientation to allow free rotation - this is required for the rotation to take effect and is handled automatically.
