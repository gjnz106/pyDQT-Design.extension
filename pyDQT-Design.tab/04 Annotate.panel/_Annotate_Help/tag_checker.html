What it does

Checks whether elements in the active view are tagged, highlights untagged elements, and flags tags that are placed too far from their element or are showing a bare "?" (a broken tag reference) - a single QA pass instead of scanning the view by eye.

Options

Categories
tick which categories to check - All/None helpers included
Include Linked Files
also checks elements from linked models
Max Tag Distance (mm)
how far a tag may sit from its element before it's flagged as "far away"

Workflow

  1. Tick the categories and set the options.
  2. Check Tags runs the scan and lists Untagged / Far / Showing "?" elements - double-click any row to zoom to it.
  3. Tag All Untagged auto-tags every untagged element found.
  4. Select Untagged selects them in Revit instead, if you'd rather tag manually.
  5. Reset Colors clears any highlight colors this tool applied; Clear All also clears the results list.
