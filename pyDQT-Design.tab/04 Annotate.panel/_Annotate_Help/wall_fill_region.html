Wall Fill Region

by Dang Quoc Truong (DQT)

Fill regions

Annotate Toolset›Wall Fill Region

What it does

Creates filled region(s) in the active plan view covering walls and/or columns, from the host model and/or linked Revit files. Footprints come from the real solid geometry (matching the elements exactly, no overhang); overlapping footprints are merged into as few regions as possible.

Modes

All cut elements in view
automatic, by cut plane + crop region
Pick in host model
pick elements one by one from the current document
Pick in linked models
pick elements one by one from a linked document

Workflow

  1. Open a plan view (floor / structural / ceiling / area plan).
  2. Run the tool and choose a mode.
  3. Pick the Filled Region Type to use, and optionally a boundary line style (or keep the region type's default).
  4. All cut elements mode: pick source model(s) and the categories to cover, then the tool builds the regions automatically.
  5. Pick modes: keep picking elements in batches - after each batch you're asked whether to pick more.

Good to know

A per-element fallback means one problematic element's geometry can't crash or block the whole run - it's skipped and the rest still complete.
