Align Viewports

by Dang Quoc Truong (DQT)

Sheet layout

Views-Sheets Toolset›Align Viewports

What it does

Aligns viewports on multiple sheets to match a chosen Main sheet's layout - crop position, view titles, and optionally titleblock placement - so a set of similar sheets (e.g. one per level) stays visually consistent without dragging each viewport by hand.

Alignment methods

Crop Box Center (default)
lines up viewport crop frames by their center
Grid Intersection
use when sheets' crops differ in size/extent (e.g. one view shows extra site context) - lines up the building inside the crop, not just the frame

Options

Overlap same-type viewports
match by name, then position - needed when a sheet has more than one viewport of the same view type
Apply same Crop / Scope Box
copies the Main sheet's crop/scope box to the others
Align View Titles
matches label position - works best together with the Crop/Scope Box option, since Revit rejects a title position outside a differently-sized crop
Include Legends
also aligns legend viewports
Match TitleBlock Type
swaps other sheets' titleblock to match the Main sheet's
Snap TitleBlocks to origin
places every titleblock at (0,0,0)

Workflow

  1. Select 2 or more sheets, then run the tool.
  2. Pick the Main sheet - the layout every other selected sheet should match.
  3. Choose an Alignment Method and tick the options needed.
  4. Click Align Viewports.
