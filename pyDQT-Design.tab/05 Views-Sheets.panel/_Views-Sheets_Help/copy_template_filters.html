Copy Template Filters

by Dang Quoc Truong (DQT)

View templates

Views-Sheets Toolset›Copy Template Filters

What it does

Copies view filters from one view template to as many other view templates as you tick. Each filter comes across exactly as Visibility/Graphics › Filters shows it in the source: its Visible and Enabled boxes and its graphic overrides (projection and cut lines, surface and cut patterns, halftone, transparency). Everything happens in one transaction, so one Undo takes it all back.

The window

1. Source
the view template to copy from - the list shows how many filters each template has (Site Plan · Floor Plan · 1 filter), so pick one that holds the filters you want to copy. Its filters are listed in Visibility/Graphics order with a line saying Visible / Hidden, Enabled / Disabled and what their overrides change (e.g. lines, patterns, transparency 40%). All are ticked at first - untick the ones you don't want; All / None do the whole list
2. Targets
every other view template that can carry filters (schedule templates can't, so they are not listed), with its view type and how many filters it has now. Search narrows the list by name or view type, and ticks are kept while you search. All shown ticks just the templates the search shows
Orange line
does not control V/G Filters - the template has V/G Overrides Filters unticked in its Include column, so whatever filters it holds never reach the views that use it
3. How to copy
see the table below; the box under it switches V/G Overrides Filters on in those orange templates (ticked by default)

Three ways to copy

Workflow

  1. Pick the source view template and untick any filter you don't want to copy.
  2. Tick the target view templates.
  3. Choose Add & update, Add only or Replace. Replace asks first and says how many filters it will take out of the targets.
  4. Click Copy Filters. A summary lists, per template, how many filters were added, updated, kept or removed, any filter Revit refused, and the templates where V/G Overrides Filters was switched on. The target list refreshes with the new filter counts.

Good to know

Filter order matters in Revit - when two filters change the same thing, the one higher in the list wins. Add & update and Add only put new filters at the bottom of the target's list and don't move the ones it already has. Use Replace when the target must end up in the same order as the source.
Copying changes the templates themselves, so every view that uses a target template picks up the filters straight away - as long as that template controls V/G Overrides Filters.
Replace with no filter ticked empties the targets' filter lists. It still asks first, and Undo brings everything back.
If Revit refuses one filter in one template (for example a filter it won't apply to that kind of view), the summary names it with ✖ and the rest of the copy still goes through.
