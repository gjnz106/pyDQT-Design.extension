Views-Sheets Toolset

05 Views-Sheets.panel

What's in this panel

5 tools for working with views and sheets: viewport alignment across sheets, isolating a linked element in a personal 3D view, batch sheet renumbering, and two full grid-based managers for sheets and views.

Align Viewports

Match viewport layout across multiple sheets to one Main sheet.

Linked Element Box

Frame a picked linked element with a section box in your own 3D view.

Sheet Re-number

Renumber a picked set of sheets sequentially, with an optional prefix.

Advanced Sheet Manager

Manage every sheet in one grid - create, duplicate, rename, delete, Excel, place views.

Advanced View Manager

Manage every view in one grid - filter, batch rename, duplicate, delete, Excel.
