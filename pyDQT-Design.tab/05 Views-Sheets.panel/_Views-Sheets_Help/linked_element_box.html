Linked Element Box

by Dang Quoc Truong (DQT)

Linked models

Views-Sheets Toolset›Linked Element Box

What it does

Picks an element inside a linked model and frames it with a section box in a 3D view - a fast way to isolate and inspect one linked element without manually drawing a section box around it.

Workflow

  1. Run the tool and pick an element inside a linked model.
  2. The tool computes the element's bounding box (transformed into host coordinates, with a small padding) and applies it as a section box.
  3. The section box is applied to - and the view switches to - your own personal 3D view.

Good to know

The section box is applied to a 3D view named "DQT Link Box - <your username>", created automatically on first use. This is deliberate: it avoids every user fighting over one shared "{3D}" view, which causes worksharing ownership conflicts.
