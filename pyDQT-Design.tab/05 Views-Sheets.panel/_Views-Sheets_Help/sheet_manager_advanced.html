What it does

Manages every project sheet in one grid, with batch tools alongside the ordinary create/rename/delete actions - built for projects with many sheets where one-at-a-time editing in the Project Browser is too slow.

Toolbar

Create Sheet
manual entry, or batch-create from an Excel list (Column A = Sheet Number, Column B = Sheet Name)
Duplicate
duplicate the checked/selected sheets, optionally multiple copies each
Rename
opens the batch rename dialog for the selected sheets
Excel
exports the current sheet list to an .xlsx file
Report
a quick export variant
Place Views
opens the views-onto-sheet placement dialog
Parameters
add extra parameter columns to the grid
Delete
deletes the checked/selected sheets

Workflow

  1. Select All / Clear All manage which sheets are checked; Refresh re-scans the model after external changes.
  2. Use the toolbar actions on the checked/selected sheets.
  3. Apply commits any pending inline edits made directly in the grid.
  4. Close exits - it warns first if there are unsaved changes.
