Sheet Re-number

by Dang Quoc Truong (DQT)

Sheets

Views-Sheets Toolset›Sheet Re-number

What it does

Renumbers a picked set of sheets sequentially, with an optional prefix - quicker than editing each Sheet Number field by hand when re-sequencing a set.

Workflow

  1. Run the tool and pick the sheets to renumber from the list (in the order you want them renumbered).
  2. Enter the starting number.
  3. Enter an optional prefix (leave blank for none).
  4. Sheets are renumbered in the order selected: prefix + starting number, then +1 for each next sheet.

Good to know

If a sheet number is already taken (would collide with another sheet in the model), that one sheet is skipped and reported in the output - the rest of the batch still completes.
