What it does

Manages every project view in one grid, with batch tools alongside the ordinary create/rename/delete actions - the view-side counterpart to Advanced Sheet Manager.

Workflow

  1. Narrow the grid with Search and the Filter dropdowns; Select All / Clear All manage the selected rows.
  2. Edit... (or double-click a row) opens the Edit Views dialog: View Name (one view at a time), View Template, Scale, Detail Level and Title on Sheet. Only ticked fields are applied, to every selected view, as one step you can Undo.
  3. Excel exports the current (filtered) view list; Refresh re-scans the model after external changes.
  4. Batch Rename opens a find/replace-style rename dialog for the selected views.
  5. Duplicate and Delete act on the selected views.
  6. Close exits the tool.

Good to know

Opening no longer freezes or crashes Revit on large models. The sheet columns used to scan every viewport in the model four times per view, so a model with thousands of views and viewports stayed "Not Responding" for minutes. It is now one scan per load. Reports, panel schedules, renderings, walkthroughs and the hidden revision schedules inside titleblocks are no longer listed - they are not views you manage here, and reading their properties could bring Revit down.
The grid is read-only; edits go through Edit... Typing straight into grid cells (and the drop-down cells) was the WPF pattern that can crash Revit under IronPython, so editing moved to the Edit Views dialog, which also changes many views at once.
Title on Sheet now shows and edits the view's own Title on Sheet parameter. It used to show the viewport's Detail Number under that header. Crop columns in the Excel export are blank for views with no crop region (sheets, schedules, legends, drafting views).
