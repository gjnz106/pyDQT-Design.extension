What it does

Manages every project view in one grid, with batch tools alongside the ordinary create/rename/delete actions - the view-side counterpart to Advanced Sheet Manager.

Stat cards

Total
views matching the current filters
Selected
rows currently checked
Types
distinct view types among the visible rows
Filters
Active/Inactive - whether any filter besides the defaults is applied

Filters

Search
matches view name
Filter

On Sheets
All Views / On Sheets / Not On Sheets

Workflow

  1. Narrow the grid with Search and the Filter dropdowns; Select All / Clear All manage the checked rows.
  2. Excel exports the current (filtered) view list; Refresh re-scans the model after external changes.
  3. Batch Rename opens a find/replace-style rename dialog for the checked views.
  4. Duplicate and Delete act on the checked views.
  5. Close exits the tool.
