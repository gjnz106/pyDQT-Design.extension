BCF / issue tracking

Data Toolset›BCF Reader

What it does

Reads BCF/BCFzip issue files - e.g. exported from IFC Delta Viewer - and lets you navigate each issue directly in the active Revit model, with per-issue viewpoints, comments, and resolved tracking.

Stat cards

Total Issues
issues loaded from the BCF file
Added
issues flagged as newly added elements
Removed
issues flagged as removed elements
Modified
issues flagged as modified elements
Resolved
issues you've marked resolved

Toolbar

Open BCF
loads a .bcf/.bcfzip file and lists its issues as cards
Zoom to Issue
flies the active view to the selected issue's viewpoint and section box
Export CSV / Export BCF (Resolved) / Export PDF
save the current (filtered) issue list
Filter chips
All / Added / Removed / Modified narrow the card list
Unresolved / Resolved chips
further narrow by resolved status

Workflow

  1. Open BCF and pick a .bcf/.bcfzip file to load its issues.
  2. Click an issue card, then Zoom to Issue to jump the active Revit view to that issue's saved viewpoint.
  3. Add a comment and mark the issue resolved once it's addressed - the Resolved chip tracks it going forward.
  4. Use the Filter and Resolved/Unresolved chips to work through the list, then Export CSV/BCF/PDF to share progress.

Good to know

This tool opens a modeless window (pyRevit's WPFWindow pattern), so you can keep it open while navigating and editing the model.
