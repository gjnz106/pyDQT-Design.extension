Contains Manager

by Dang Quoc Truong (DQT)

Spatial containers

Data Toolset›Contains Manager

What it does

Finds elements physically inside Rooms, Areas, Spaces, Zones, Masses or Scope Boxes and lets you assign a built value (e.g. Number_Name) to a parameter on every matched element in bulk - the reverse direction of Room Data Collector.

Stat cards

Rooms / Areas / Spaces
count of each spatial type in the model
Zones / Masses / ScopeBox
count of the remaining container types
Found
elements matched by the last Find

Workflow

  1. Pick the spatial container type (Rooms/Areas/Spaces/Zones/ Masses/Scope Boxes) and the element categories to scope.
  2. Find scans which elements fall inside each container.
  3. Visualize highlights the found groups in the model; Select adds them to the active Revit selection.
  4. Set Parameter Value writes a value built from the container's own parameters (e.g. Number and Name, joined by a separator) into a chosen parameter on every found element.
  5. Reset clears the current results and view-only scoping.
