Foundation Volume

by Dang Quoc Truong (DQT)

Volume write-back

Data Toolset›Foundation Volume

What it does

Writes Revit's computed volume into a selected instance parameter on every Structural Foundation element in the active document - useful for BOQ takeoff parameters that need a plain number rather than a schedule-calculated field.

Layout

Search
filters the parameter list by name
Parameter list
every writable instance parameter already present on the foundations
Status panel
reports how many elements succeeded, and why any were skipped

Workflow

  1. Search and pick the target parameter from the list - it must be a writable instance parameter already present on the foundations.
  2. Write Volume writes each foundation's computed volume (HOST_VOLUME_COMPUTED) into that parameter.
  3. Check the status panel for the success count and any skip reasons (parameter not found, read-only, or an error).

Good to know

This tool only writes to a parameter that already exists on the foundations - it doesn't create shared parameters. Add the parameter first (e.g. with Parameter Loader) if it isn't there yet.
