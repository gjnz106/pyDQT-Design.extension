06 Data.panel

What's in this panel

9 tools for moving data between elements, spatial containers, BCF issues, and Excel: parameter transfer/aggregation, volume write-back, BCF issue review, schedule round-tripping, and batch text/schedule utilities.

Transfer Parameter Value

Copy a parameter's value into another parameter on the same elements.

Foundation Volume

Write computed volume into a parameter on Structural Foundations.

In-Place Volume

Write computed volume into a parameter on In-Place family instances.

Contains Manager

Find elements inside Rooms/Areas/Spaces and assign them parameter values.

Room Data Collector

Aggregate element data inside Rooms/Areas/Spaces back into a spatial parameter.

BCF Reader

Read BCF/BCFzip issue files and navigate each issue in the model.

Schedule Link Pro

Export a schedule's live element data to Excel, edit, then import it back.

Schedule Duplicator

Batch-duplicate a schedule with an optional view template and naming pattern.

Text to Element

Transfer Text Note content into a parameter on the elements it overlaps.
