In-Place Volume

by Dang Quoc Truong (DQT)

Volume write-back

Data Toolset›In-Place Volume

What it does

Writes each In-Place family instance's computed volume (m³) into a selected instance parameter - e.g. for rock armour or precast unit BOQ takeoff, where the mass is modeled as an in-place family.

Scope

With a selection
only the In-Place elements in your current selection
With nothing selected
every In-Place family instance in the document

Workflow

  1. Optionally pre-select specific In-Place elements before running the tool - otherwise it scopes to the whole document.
  2. Search and pick the target parameter from the list - it must be a writable instance parameter already present.
  3. Write Volume writes each element's computed volume (m³) into that parameter.
  4. Check the status panel for the success count and any skip reasons.

Good to know

Like Foundation Volume, this only writes into a parameter that already exists - create it first if it isn't on the family yet.
