by Dang Quoc Truong (DQT)

Spatial containers

Data Toolset›Room Data Collector

What it does

The reverse of Contains Manager: collects a parameter's values from elements inside Rooms/Areas/ Spaces and aggregates them back into a parameter on each spatial element - e.g. total furniture count per room, or a comma list of equipment tags in a space.

Aggregation methods

Sum / Average / Min / Max
numeric aggregation across the matched elements' values
Count
how many matched elements were found
First / Last
the value from the first or last matched element
List / Unique List
every value (or every distinct value) joined into one string

Workflow

  1. Pick the spatial type (Rooms/Areas/Spaces) and the element categories to scan.
  2. Collect Data finds the elements inside each spatial element.
  3. Choose the source element parameter and an aggregation method.
  4. Apply to Rooms writes the aggregated value into the chosen spatial parameter.
  5. Select Elements adds the matched elements to the active selection for a manual check.
