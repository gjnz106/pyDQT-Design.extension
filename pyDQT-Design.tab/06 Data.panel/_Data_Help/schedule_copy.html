What it does

Batch-duplicates a schedule a set number of times, with a shared naming pattern, a duplicate method, and an optional view template applied to every copy - quicker than duplicating and renaming one schedule at a time.

Workflow

  1. Select the source schedule from the list.
  2. Enter the number of copies to create.
  3. Enter a base name - each copy is named <base>_<n>.
  4. Pick a view template: keep the source's current template, reuse it explicitly, pick another schedule template, or apply none.
  5. Pick the duplicate method - Duplicate, As Dependent, or As Independent.
  6. Confirm applying the template (if one was picked), then the tool creates all copies and reports how many succeeded.

Good to know

If a chosen view template isn't valid for the schedule's fields, that copy is still created but the template isn't applied - check the summary message for which copies were affected.
