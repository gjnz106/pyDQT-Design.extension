Schedule Link Pro

by Dang Quoc Truong (DQT)

Excel round-trip

Data Toolset›Schedule Link Pro

What it does

Exports a schedule's live element data to Excel for offline editing, then imports it back and writes the changed cells into the model - reading straight from the underlying elements rather than the schedule's own cells, so it works with calculated and read-only fields too (DiRoots-style).

Layout

Schedule picker
choose the schedule to work with
Preview
loads the schedule's rows into the on-screen grid
Keep Formatting
exports a read-only copy that mirrors the schedule's own appearance and calculated fields
Debug Info
shows the last export/import/update log

Workflow

  1. Pick a schedule, then Preview to see its rows in the grid.
  2. Export to Excel saves an editable copy of the visible data.
  3. Edit values in Excel and save the file.
  4. Import Excel loads the edited file back and highlights the changed cells.
  5. Update Model writes the changed cells into the real elements.

Good to know

If Office Excel Interop isn't installed, the tool falls back to a native .xlsx reader/writer (zipfile + XML) - export and import still work, just without any COM dependency on Excel being installed.
