Text to Element

by Dang Quoc Truong (DQT)

Annotation to parameter

Data Toolset›Text to Element

What it does

Transfers the text content of Text Notes into a parameter on model elements that overlap them in the active view - useful for auto-assigning names, area labels, or other annotations that were placed as plain text instead of a real parameter value.

Workflow

  1. Step 1: pick text notes by selecting them, or use every text note already in the current view.
  2. Step 2: pick the target category (Walls, Floors, Rooms, Doors, Furniture, and more).
  3. Step 3: pick the target parameter - only writable text parameters found on a sample of the target elements are listed.
  4. Step 4: set the intersection tolerance in millimeters (default 150mm) - how close a text note's bounding box needs to be to an element's to count as a match.
  5. Review the preview of matches, confirm, and the tool writes each note's text into the chosen parameter on its matched element.

Good to know

Matching is done by 2D bounding-box overlap in the active view, not by exact geometry - if you get zero matches, try a larger tolerance, since text placement rarely lines up pixel-perfect with an element's box.
