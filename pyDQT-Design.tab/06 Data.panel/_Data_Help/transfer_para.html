Transfer Parameter Value

Parameters

Data Toolset›Transfer Parameter Value

What it does

Copies values from one parameter into another parameter, within the same elements, for a chosen category. Supports all StorageTypes (String, Double, Integer, ElementId) and converts between them where possible.

Layout

Category
scopes which elements are read/written; the element count updates next to it
SOURCE Parameter
the parameter to read from - search box filters the list
TARGET Parameter
the parameter to write to - search box filters the list
Preview
shows each element's current Source/Target value before you commit

Workflow

  1. Pick a Category to scope the elements.
  2. Choose a Source Parameter and a Target Parameter from that category's available parameters.
  3. Refresh Preview lists what each element's transfer will look like.
  4. Transfer Values writes Source's value into Target for every listed element.

Good to know

A StorageType mismatch (e.g. Text source into a Number target) is converted automatically where the value is convertible; values that can't convert are skipped and counted separately in the results.
