Color Splasher

by Dang Quoc Truong (DQT)

Data visualization

Settings Toolset›Color Splasher

What it does

Colors elements in the active view based on a chosen parameter's value, so patterns in the model data (by level, phase, system type, status, and so on) become visible at a glance - with a legend and matching real Revit view filters generated from the same color scheme.

Layout

Source
the active model, or a loaded linked model
Category
scopes which elements are read
Parameter list
search box filters it; pick the parameter whose values drive the coloring
Color list
one row per distinct value found, with its assigned color - click a row's swatch to pick your own color

Workflow

  1. Pick a Source (current model or a link), then a Category and a Parameter - the value list populates automatically.
  2. Gradient Colors or Random Colors auto-assigns a color per value, or click any row to pick a color by hand.
  3. Apply Colors sets a graphic override on every matching element in the active view (via View Filters when the source is a link, so it works across linked models too).
  4. Create Legend places a legend view text/color key for the current scheme; Create View Filters turns the same colors into real, reusable Revit view filters.
  5. Save Colors... / Load Colors... save or reuse a color scheme as a file, e.g. to keep the same value-to-color mapping across models.
  6. Reset clears every override this tool applied to the active view.

Good to know

Loading a saved color scheme reports how many values matched, and lists any values in the current model that weren't in the saved file (so you can assign them) and any saved colors that no longer apply.
